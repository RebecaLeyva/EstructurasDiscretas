# README Practica 1
----

1. El objetivo de esta práctica es instalar en nuestro sistema GHC y Git, así como crear nuestra cuenta de GitHub. Estas herramientas las usaremos en el futuro para subir nuestras prácticas de Estructuras Discretas. Aprender a hacer uso de estas tecnologías nos ayudará en el futuro a trabajar en equipo de manera más eficiente y cómoda.

2. La práctica me tomó aproximadamente 1 hr y 30 min, aunque la hice durante varios días, unos cuantos minutos cada día.

3. La primera vez que intenté instalar Haskell, la instalación falló debido a que no contaba con un compilador de C; tuve que instalarlo para poder continuar. En el último intento tuve éxito.
