**¿Cuáles son las principales diferencias entre Haskell y Rust?**

Haskell y Rust son lenguajes de programación con tipado fuerte, pero tienen enfoques diferentes. Haskell se basa principalmente en la programación funcional pura, la inmutabilidad y la abstracción matemática, mientras que Rust es multiparadigma y se enfoca en el rendimiento, la seguridad de memoria y el control de recursos mediante el sistema de ownership. Haskell se utiliza especialmente en contextos académicos y funcionales, mientras que Rust es común en el desarrollo de sistemas y aplicaciones de alto rendimiento.

**¿Por qué Haskell no ha alcanzado una adopción significativa en la industria del software?**

Haskell no ha alcanzado una adopción significativa en la industria principalmente porque tiene una curva de aprendizaje elevada, un ecosistema y mercado laboral más pequeños y una sintaxis y paradigma funcional que pueden resultar menos familiares para muchos programadores. Además, ya existen lenguajes demasiado establecidos como Java, C++, Python o JavaScript, por lo que no existe un gran incentivo para cambiar.

**Si tuvieras que explicarle a una persona que no es de CC la función que cumple Git frente a la de GitHub, ¿cómo se lo explicarías?**

Git es una herramienta que nos permite guardar y organizar los cambios que realizamos en nuestros trabajos, como si se tratara de guardar diferentes borradores de un escritor. De esta manera, podemos llevar un control de las modificaciones y recuperar versiones anteriores cuando sea necesario.

GitHub, en cambio, es un servicio en la nube que permite almacenar repositorios de Git de manera remota. Podemos imaginarlo como un lugar en Internet donde guardamos nuestros proyectos, similar a subir un cuaderno a un espacio de almacenamiento en línea, para poder acceder a ellos desde otros equipos y también compartirlos con otras personas sin necesidad de transportarlos físicamente.
